🚗 Pátio Rápido — Sistema Inteligente de Gestão de Frotas e HigienizaçãoO Pátio Rápido é um aplicativo web (PWA) de alta performance desenvolvido com foco em UX de Guerrilha e Mobile-First. A aplicação resolve dores operacionais reais de operadores de pátio em frotas corporativas, permitindo o registro ágil de higienização de veículos sob condições de campo (luz solar direta, alta velocidade e turnos de madrugada).🌟 Principais Funcionalidades📸 Leitor de Placas por Inteligência Artificial (OCR via Google Gemini): Captura a foto da placa e do veículo, enviando para a API do Gemini processar e preencher automaticamente os dados em segundos.🌙 Turnos Noturnos & Dia Operacional Inteligente: Cálculo automatizado do dia operacional (das 06:00 às 05:59 do dia seguinte) e filtros avançados de data/hora para turnos de madrugada.📊 Relatórios Corporativos em PDF (Landscape): Exportação instantânea de extratos individuais de turno formatados profissionalmente via jsPDF e jspdf-autotable.🔒 Autenticação e Privacidade Individual: Sistema de controle de acesso por Matrícula e PIN de 4 dígitos com isolamento estrito de dados por operador.📖 Manual Operacional Integrado: Dicas de enquadramento, iluminação e melhores práticas embutidas na interface do app.🚀 Como Executar o Projeto LocalmenteClone o repositório:git clone https://github.com/Guidersonkoft/patio-rapido.git
cd patio-rapido
Instale as dependências:npm install
Configure as Variáveis de Ambiente:Crie um arquivo chamado .env na raiz do projeto e insira sua chave da API do Gemini:VITE_GEMINI_API_KEY=sua_chave_real_aqui
Inicie o servidor de desenvolvimento:npm run dev
